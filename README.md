# Pantry-Tracker

**Pantry Tracker** is a web application that helps users efficiently manage the items in their kitchen pantry. With this app, users can add, update, and delete pantry items, track expiration dates, and generate shopping lists based on current inventory and usage. The system also sends alerts for items that are about to expire, helping reduce food waste and improve planning.

---

##  Features

-  **User Authentication** (Email/Password or Google Sign-In)
-  **Add, Edit, and Delete Pantry Items** (name, quantity, expiry date)
-  **Automatic Expiry Notifications**
-  **Generate a Smart Pantry List** based on consumption
-  **Create Shopping Lists** from missing or low-stock items


---

##  Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend/Database**: Firebase Firestore
- **Authentication**: Firebase Authentication
